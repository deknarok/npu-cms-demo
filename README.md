# ต้นแบบระบบบริหารจัดการหลักสูตร มหาวิทยาลัยนครพนม (ฉบับนำเสนอ)

© บริษัท ไบต์เฟล็กซ์ จำกัด — เอกสารและซอฟต์แวร์ต้นแบบเพื่อการนำเสนอเท่านั้น ห้ามคัดลอก ดัดแปลง หรือเผยแพร่ต่อโดยไม่ได้รับอนุญาต

- เปิดใช้งาน: GitHub Pages ของ repo นี้
- ข้อมูลหลักสูตร บุคลากร และสถิติเป็นข้อมูลจริงจากระบบทะเบียนและ ERP-HR (อ่านอย่างเดียว) · **ไม่มีเลขประจำตัวประชาชน** หรือข้อมูลส่วนบุคคลอื่น (ที่อยู่ เบอร์โทร วันเกิด เงินเดือน)
- สลับบทบาทผู้ใช้ได้จากปุ่มมุมขวาบน · ข้อมูลที่แก้ในหน้าเว็บเก็บในเบราว์เซอร์ของผู้ชมเท่านั้น (ปุ่ม "รีเซ็ตข้อมูลจำลอง" เพื่อเริ่มใหม่)
